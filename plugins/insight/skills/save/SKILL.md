# Insight에 저장

Insight MCP 서버의 `find_themes`, `save_insight` 도구를 쓴다 (도구 이름이 그렇게 끝난다). 도구가 보이지 않으면 "설정 → 커넥터에서 Insight(https://insight.smoh.dev/mcp)를 연결해 주세요"라고 알리고 멈춘다.

1. `find_themes`로 이미 있는 원칙을 확인한다.
2. 이 대화의 **사용자 메시지만** 근거로 초안을 만든다. 주제가 주어지면($ARGUMENTS) 그 주제만 본다.
   - 사용자의 원문(seed)이 있는 것만 뽑는다. AI가 혼자 한 주장은 사용자 인사이트가 아니다.
   - 빼는 것: 단순 수락("ㅇㅇ", "좋아", "진행해"), 기준이 드러나지 않은 작업 지시, 사실·일정, 사용자가 붙여넣은 글
   - 사용자의 의문을 AI가 표현으로 정리했고 사용자가 그 위에서 이어갔다면 reaction은 articulated, AI 표현도 원문 그대로 붙인다
   - AI 제안을 사용자가 반박·거절했다면 kind는 rejection, 무엇을 제안했는지 ai_proposal에 한 줄로 적는다
   - 비밀값(토큰, API 키, 비밀번호, 사내 주소)은 어느 칸에도 넣지 않는다. 사용자 원문이라도 그 부분은 `<비밀값>`으로 바꾼다
3. 초안은 번호를 붙여 보여 준다. 출처를 섞지 않는다.
   ```
   1. <유형> · <반응>
      "<한 문장>"
      · 내 말: "<사용자 원문 그대로>"
      · AI 표현 / AI 제안: <있을 때만>
      · 테마: <기존 테마(몇 번째 등장) 또는 새 테마 제안>
   ```
4. 사용자가 OK하면 `save_insight`로 저장한다. "1, 3만", "2는 이렇게"는 반영해 다시 확인한다. 답이 없으면 저장하지 않는다.
5. 저장 후 한 줄로 끝낸다: 몇 개 저장했는지, 어떤 테마에 묶였는지. 대시보드는 https://insight.smoh.dev
